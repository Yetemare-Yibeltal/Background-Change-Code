# AuraStudio — Background & Pattern Customizer

A modular Web application built with Vanilla HTML5, CSS3 (Custom Properties), and JavaScript ES6 Modules.

## Features

- **Solid Color Tuning:** High precision HEX color picker with opacity management.
- **Gradient Engine:** Supports Linear, Radial, and Conic gradients with customizable color stops.
- **SVG Pattern Generator:** Dynamic vector background patterns rendered via SVG data URLs.
- **Image Filters:** Custom background image processor featuring blur and brightness adjustment parameters.
- **Export System:** One-click CSS code export with direct clipboard integration.
- **State History:** Undo and redo state stack for tracking changes during customization.
